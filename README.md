# 💰🎮 Money‑Master

**Money‑Master** is a game project where players aim to rise to the top and become the ultimate **Money Master** by defeating the evil and corrupt Money Master. The game blends strategy, progression, and interactive gameplay to create an engaging experience centered around growth, decision‑making, and challenge.

This project was built as a learning and creative exercise, combining game design concepts with programming and logic.

---

## 🧠 Concept & Goal

The core objective of **Money‑Master** is simple:

> **Outplay, out‑earn, and ultimately defeat the corrupt Money Master.**

Players progress through the game by improving their abilities, making smart choices, and overcoming obstacles that stand in their way.

---

## ✨ Features

* 🎯 Clear win condition: defeat the corrupt Money Master
* 🕹️ Interactive gameplay with progression
* 🧠 Strategy‑based decision making
* 🎮 Built using game‑development tools and scripting
* 📦 Lightweight and easy to run

---

## 🛠 Technologies Used

Depending on the version and setup of the project, Money‑Master uses:

* **Godot Engine** (GDScript)
* **Piskel** (Game Art)
* **Chrome Music Lab** (Game Music)

These technologies allow for flexible gameplay logic and easy expansion.

---

## ▶️ How to Run the Project

### Run with Godot

1. Download and install **Godot Engine** (version depends on project setup)
2. Clone the repository:

```bash
git clone https://github.com/RianThomas/Money-Master.git
cd Money-Master
```

3. Open the project folder in Godot
4. Press **Run ▶️** inside Godot

* The difficulty increases as the player approaches the final confrontation
* Victory is achieved by defeating the corrupt Money Master
